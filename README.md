# OneLifeData7

![](https://opencollective.com/twohoursonelife/tiers/badge.svg)

This repository contains all content (data) changes for **Two Hours One Life**, including art, objects and
recipes.

For other changes, please see
- [OneLife](https://github.com/twohoursonelife/OneLife) (server, client and editor code)
- [minorGems](https://github.com/twohoursonelife/minorGems) (engine)

## Contributing
Please ensure you are familiar with our data contribution guidelines found [here](https://github.com/twohoursonelife/OneLifeData7?tab=contributing-ov-file)
**before** opening a pull request. Contributions that do not meet these guidelines
will be rejected.
